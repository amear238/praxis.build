# Opening Range Breakout on the $150,000 Frame: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Find out whether any variation of the opening range breakout passes the five bars on the $150,000 MyFundedFutures frame, with each variation's size set from 2021 to 2023 so survival is designed in, not hoped for.

**Architecture:** An ORB engine (`orb_engine.py`) returns trades and day lines in the exact shape of the Noise-Area engine's result, so the existing bars (`gates.judge`) and the $150,000 extras (`run_150k.info`) are reused unchanged. An independent replay (`orb_check.py`) checks every trade without importing the engine. A measuring pass runs a fixed grid at one micro on 2021 to 2023 and computes a safe size per rule; the lead fixes up to eight settings files; `run_orb.py` runs and judges them.

**Tech Stack:** Python 3, standard library only, `unittest`. Run every file as `python3 -I -B <file>` from the repo root.

**Spec:** `docs/superpowers/specs/2026-11-17-orb-150k-design.md`. Amear's rulings: `RULINGS.md`. The engine conventions being matched: the docstring of `research/noise-area-variations/engine.py`.

- No decision on a bar stamped after 15:58. Flat: on the bar stamped 15:59 (or the last tradable bar), at the next bar's open, 2 ticks against; on the last tradable bar, at its close.
- No result is looked at before the settings that produced it are committed.

- No timestamp typed by hand. No email, phone number or staff name in any file. Anything Amear reads: plain English, dollars.

## Review Focus

1. A day whose opening range is incomplete (any bar stamped 09:31 to 09:30+n missing): no trade that day, not a skip. (Task 1)
2. A bar that opens beyond the stop: the stop fills from the open, `gap` true, loss above planned, not a rule break. (Task 1, Task 2)
3. A target and stop touched in the same minute: the stop. A target on the entry bar can fill. (Task 1)
4. A half day ending before 15:59: closed at the last tradable bar's close, never carried. (Task 1)
5. The 14-day range average on the first 14 days of data: absent, so `atr_frac` and `max_or_atr` rules take no trade those days, and the frequency calendar starts on the first day the rule can trade. (Task 1, Task 5)

### Task 1: The engine (tester)

**Files:** Create `research/orb-150k/orb_engine.py`, `research/orb-150k/test_orb_engine.py`

**Interfaces:**
- Consumes: `globex.Day`, `globex.Bar`, `globex.tradable_end`, `globex.sm_of` (imported from `research/noise-area-variations/` by path).
- Produces:
  - `FIELDS = ("name", "reason", "or_minutes", "entry", "entry_until", "sides", "stop", "exit", "max_or_atr", "risk_pct")`. `validate(s) -> None`, raises `ValueError` on any other key, a missing key, or a value outside: `or_minutes` in (5, 15, 30); `entry` in ("direction", "break"); `entry_until` "HH:MM" after the range and before 15:59 when entry is "break", else null; `sides` in ("both", "long", "short"); `stop` one of `["far_side"]`, `["or_frac", x>0]`, `["atr_frac", x>0]`; `exit` one of `["hold_to_flat"]`, `["target_r", x>0]`, `["trail_r", x>0]`; `max_or_atr` null or > 0; `risk_pct` in (0, 5].
  - `opening_range(day, n) -> (o, h, l, c) | None`: bars stamped 09:31 .. 09:30+n all present and inside the tradable bars; o = first open, c = last close.
  - `atr14(days, k) -> float | None`: mean of (max high - min low) over bars stamped 09:31 to 16:00 of the 14 days before `days[k]` that have a bar stamped 09:31; None when fewer than 14.
  - `run(days, settings, fill="midpoint", start=150000.0, fixed_qty=None) -> {"settings", "fill", "start", "trades", "days", "skipped", "filtered", "digest"}`. Trades and day lines exactly as in the Noise-Area engine docstring ("Trade:", "Day:", "digest"), except `reason` in ("stop", "target", "flat"). `skipped`: list of {date, reason} with reason "stop under 10 points" or "under one contract". `filtered`: dates where `max_or_atr` removed the day. `fixed_qty`: when set, qty is that number and the balance does not limit it (measuring pass only).

Rule per day (the decision bar is D, its close C):
- `direction`: D is the range's last bar. Side long when c > o, short when c < o, none when equal or that side is not allowed.
- `break`: D is the first bar after the range, stamped no later than `entry_until`, whose close is > h (long) or < l (short); a close beyond a side not allowed is ignored and the search continues.
- No entry if the bar after D is missing, is the day's last tradable bar, or is stamped 15:59 or later.
- `max_or_atr`: no trade when atr14 is None or (h - l) > x * atr14; the date is added to `filtered`. `atr_frac` with atr14 None: no trade, not filtered, not skipped.
- dist from C: `far_side` long C - l, short h - C; `or_frac` x * (h - l); `atr_frac` x * atr14; floored to the tick. Size as the Noise-Area engine, qty capped at 90, balance = start + net of trades closed before D.
- Entry at the next bar's open, 2 ticks against, inside the bar. Stop rests at entry -/+ dist. Target (exit target_r) rests at entry +/- x * dist, rounded to the tick away from the entry; fills at the target price on the first bar, from the entry bar, whose high >= target + 0.25 (long) or low <= target - 0.25 (short), unless the stop is reached on that bar. Trail (exit trail_r): at each bar's close the stop moves to best -/+ x * dist on the tick grid away from price, only toward price, acting from the next bar; best includes the entry bar.
- Each bar in the trade, from the entry bar: stop check first, then target, then flat.

### Task 2: The independent rule check (tester, then checker)

**Files:** Create `research/orb-150k/orb_check.py`, `research/orb-150k/test_orb_check.py`

**Interfaces:**
- Consumes: a `run` result (Task 1), `globex`.
- Produces: `rule_check(result, days) -> list[str]`, empty when clean. Must not import `orb_engine`. Recomputes from the written rule, for every trade: the range, the decision bar and side, that no earlier bar that day qualified (for `break`), atr14 when used, dist, size, entry fill, the bar-by-bar life of the trade under the result's fill model, reason, exit, gap, net, r, balance; one trade a day; the day lines (start, end, low). On "kind", a loss above planned_cost by more than a cent without gap is a break. Also: every date where the rule would have traded (range complete, side found, size >= 1, dist >= 10, not filtered) has a trade, so no signal is silently lost.

### Task 3: The measuring pass (tester)

**Files:** Create `research/orb-150k/measure.py`, `research/orb-150k/test_measure.py`

**Interfaces:**
- Consumes: `orb_engine.run` with `fixed_qty=1`, fill "midpoint", start 150000, on days dated up to 2023-12-31 (load with `end="2023-12-31"`).
- Produces: `grid() -> list[settings]` (3 or_minutes x 2 entries x 3 stops [`far_side`, `or_frac 0.5`, `atr_frac 0.10`] x 6 exits [`hold_to_flat`, `target_r 3`, `target_r 5`, `target_r 10`, `trail_r 1`, `trail_r 2`] = 108; sides "both"; entry_until "11:00" for break; max_or_atr null; risk_pct 1.0, unused); `dd975_r(day_rows, runs=2000, seed=20261115) -> float`; `measure(days) -> list[row]`; writes `research/orb-150k/out/measure.json` and `out/MEASURE.md`.
- R per trade = net / planned_cost. Day rows in R: for each date with a trade, (day end - day start) / planned_cost and (day low - day start) / planned_cost. `dd975_r`: shuffle the day rows `runs` times (random.Random(seed)); for each order, the largest (highest end-of-day balance so far - a day's low) in R; return the 97.5th percentile (sorted list, index ceil(0.975 * runs) - 1).
- Row fields: `name` (e.g. `or5-direction-far_side-target_r10`), settings, trades, skipped (stop under 10), win_pct, avg_winner_r, avg_r, net_r, net_r_by_year {2021, 2022, 2023}, net_r_long, net_r_short, longest_losing_run, max_gap_days (calendar: trading days with a 09:31 bar, from the first day the rule could trade), dd975_r, safe_dollars_per_r = 4500 / dd975_r, projected_profit = net_r / years_measured * safe_dollars_per_r * years_full (years from trading-day counts: measured days / full days ratio), headroom = projected_profit / 9000, net_r_by_or_tercile (terciles of (h - l) / atr14 on the days with atr14, cut points from those days).
- MEASURE.md: one table sorted by headroom, plain column names, and a line stating the number of rules measured.
