## 5. Roll-detection rule as implemented (with tie-break)

For each adjacent pair `(front C_i, back C_{i+1})`, over the **dates present in BOTH** daily series in chronological order, the roll date is the **first** date on which:

```
back.volume  >  front.volume     AND     back.open_interest  >  front.open_interest
```

**Tie-break / determinism (documented):**
- **Strict** `>` on **both** legs — an exact tie does **not** trigger the roll (prevents a coin-flip on equal values).
- **Earliest** qualifying common date wins.
- Only **overlap** dates are compared — no interpolation onto non-common dates.
- `confirm` (default **1**) = the joint condition must hold for N consecutive common dates; default 1 is the plain single-day reading of spec §3, `--confirm N` hardens against a one-day liquidity spike.
- If OI is absent → **refuse** (`OIBlankError`), never fall through to volume-only, unless `--allow-volume-only` is explicitly passed (then `oi_used=False` is recorded in the diagnostics and a banner is printed).
- If **no** crossover exists in the overlap → `StitchError` (flag loudly; do not guess a date).

## 6. Difference-offset math

Contracts chronological `C1…Cn`; seam `R_i` is the `C_i → C_{i+1}` roll date. Reference price = **daily close on the roll date** (nearest daily close on-or-before `R_i`).

```
gap_i    = close_{C_{i+1}}(R_i) − close_{C_i}(R_i)     # raw contract spread at the seam
off(Cn)  = 0                                           # newest contract is the anchor (unadjusted)
off(C_i) = off(C_{i+1}) + gap_i                        # accumulate BACKWARD in time
adjusted_price(bar of C_i) = raw_price + off(C_i)      # ADDITIVE — same constant for every C_i bar
```

Worked fixture (2 seams so accumulation is exercised):
- R1 `03-24→06-24` @ 2024-03-15: gap1 = 18050 − 18000 = **+50**
- R2 `06-24→09-24` @ 2024-06-14: gap2 = 18540 − 18500 = **+40**
- `off(09-24)=0`, `off(06-24)=+40`, `off(03-24)=+40+50=**+90**`

Why this is Difference and not Ratio: the offset is an **additive constant per contract**, so absolute point distances (channel widths, ATR, stop distances — the Block-2 breakout inputs, spec §2.2) are **invariant**. A ratio adjustment would multiply, shifting different-priced bars by different absolute amounts — the self-test asserts two different-priced C1 bars (17980, 17998) **both** move by exactly +90, which a ratio adjustment cannot do.

## 11. Spec ambiguity resolved

- **Offset reference price:** spec §3 says roll "on the day" of crossover but does not name the price used to size the Difference offset. Chosen: the **daily settlement/close on the roll date** (nearest on-or-before), the standard Panama reference and the value the coworker's daily export carries. Documented in `build_offsets()`.
- **Seam boundary ownership:** bars with `date < R_i` use the front contract; bars with `date >= R_i` use the back contract — clean, non-overlapping, monotonic seams (no double-counting on the roll day).
- **"Confirmed by open interest":** implemented as a hard **AND** (both legs strict) rather than OI as a soft tiebreaker, matching the stricter reading and the trader-locked "OI-confirmed" language; single-day trigger by default, `--confirm N` available.
