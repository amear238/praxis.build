## Roll-convention recommendation + rationale

**RECOMMENDED (trader to lock): volume/OI-crossover roll trigger + Difference (back-adjusted / "Panama") adjustment.**
- The Block-2 strategy is a volatility/channel breakout measuring signals as absolute point distances (Q7 optimizes lookback / noise multiplier / stop-ATR multiplier). **Difference back-adjustment** removes the raw price gap at each roll seam that would otherwise read as a fake range expansion → fabricated breakouts / fake stop-outs (~4 seams/yr), while preserving the true point size of every move.
- **Ratio (percentage) adjustment rejected:** it preserves returns but distorts absolute point distances — corrupting the exact inputs being optimized. Point/tick/R sizing (Q6) makes Ratio's percentage fidelity irrelevant.
- **Volume/OI roll** (not fixed calendar) keeps the series on the actually-traded liquid contract for realistic Q5 fills/slippage.
- Disclosed cost: absolute historical price levels become synthetic (can go negative deep in history) — acceptable because nothing compares to an absolute price level; flagged in-spec if such a rule is ever introduced.
- Marked **RECOMMENDED — trader to lock** in both spec §2 and DECISIONS.md because roll construction materially changes backtest P&L; not self-certified.
