The cast of characters

Six pieces, in plain language

The system is a relay race. A signal is spotted, passed hand-to-hand, and ends as a real order at the exchange. Each runner has one job.

The Scout

TradingView

Watches the NASDAQ futures chart and shouts when the strategy's setup appears. This is where a trade idea is born.

The Mailroom

n8n

Catches the shout, checks it, and drops a clean note (a small order ticket) into a mailbox folder.

The Hands

NinjaTrader 8

Watches the mailbox. The moment a note lands, it places the order — with a stop-loss and a profit target attached automatically.

The Phone Line

Rithmic

The professional connection that carries the order from our software to the actual exchange.

The Account

MFFU

The funded trading account (a prop firm). Their money, their rules — which is exactly why the safety layer matters.

The Overseer

Git + Telegram

Every change is recorded, and the system texts a human on every meaningful event. Nothing happens silently.

Why this shape? By splitting the job into small runners, any one of them can fail safely — the order never places itself out of a note that wasn't checked first.

Quality control · what "audited" means

Nothing grades its own homework

Every code change is written by one worker and then independently graded by a separate auditor before it's allowed to be saved. If the auditor says FAIL, it doesn't get committed — the tooling enforces this, not good intentions.

Checks that have already caught real problems:

  • Speed & reliability audit — found delivery was secretly slow (a throttle bug); re-architected the relay to under 1.3 seconds.
  • Offline drill — pulled the plug mid-flight; found a silent signal-loss gap and fixed it with a backlog detector.
  • Order-safety audit — caught the strategy quietly exposing two "tunable knobs" that would have let it be over-fitted; removed them.
  • Duplicate & replay tests — proved the same signal can never fire twice, even across a restart.
  • Concurrency incident — two sessions collided once; response was a hard "one session per repo" lock enforced by tooling.
Honest assessment · where it's fragile

The weakest links today

Being built carefully doesn't mean being finished. Here's what I'd flag — biggest first.

Bottleneck

Progress depends on manual VM steps

The entire backtesting block is stalled on two hands-on tasks in the Windows virtual machine — pulling the price history and compiling the strategy. Human-gated, one person, one machine.

Blocker

A rendering bug in the Windows VM

NinjaTrader on the emulated Windows machine has hit a display crash that blocks new windows from opening. It has a workaround (restart) but it's a lurking fragility on the one machine that runs orders.

Unproven

The edge isn't proven yet

We've built the machine that places trades, but backtesting — the rehearsal that shows the strategy actually makes money out-of-sample — hasn't produced results yet. The gun is loaded; we haven't checked it shoots straight.

Deferred

No public "front door" yet

Real TradingView signals arrive over the open internet; that secure entry point is deliberately postponed to pre-live. It's a known gap, not an oversight — but it's untested.

Hardware

Runs on a Mac + emulated Windows

Fine for building. Before real money, the plan requires a dedicated native Windows PC — that migration is still ahead of us.

Watch

Alerting only half-tested

The "something's wrong" Telegram alerts have been tested in a dry run but not fully live-fired, and a token rotation is pending. Low severity, but it's the safety net for everything else.

Safety layer 1 · per order

Nine circuit breakers

Automatic switches that halt trading on the spot — too many losses, an odd fill, a bad connection. Built & individually test-fired in Block 3.

Safety layer 2 · per day

Strategy Health Monitor

A daily after-close check that compares live results to the backtest. If the edge decays, it demotes the strategy and texts a human. Plain arithmetic — no AI in the loop.

And one human gate: before a single dollar trades, the trader must explain — from memory, no notes — what triggers an entry, an exit, and every circuit breaker. Pass/fail, no partial credit. Paper profits do not unlock it.
